AR/MR Музей — Meta Quest 3S

1. Файл index.html нужно разместить на HTTPS-сайте (например GitHub Pages).
2. Откройте адрес сайта в браузере Meta Quest Browser.
3. Нажмите кнопку VR/Enter VR.
4. Разрешите необходимые запросы браузера.
5. Наводите луч контроллера на объекты «История», «Культура», «Природа», «Холл» и нажимайте курок.

Важно:
Это стартовый WebXR-прототип. Возможности реального passthrough/смешанной реальности
зависят от поддержки WebXR браузером и разрешений Meta Quest.
Для полноценного распознавания реальных музейных объектов по камере лучше делать
отдельное приложение под Quest (Unity + Meta XR SDK).
